# depgraph - граф зависимостей пакетов Python

## 1. Общее описание

Консольная программа на Python, которая строит граф зависимостей пакета
в формате pip (Python). Готовые менеджеры пакетов и сторонние библиотеки
для получения зависимостей не используются: данные берутся из JSON-описания
пакета на сайте репозитория (по умолчанию PyPI), а строки зависимостей
разбираются вручную.

Что умеет программа:

- строит граф зависимостей (в том числе транзитивных) обходом в ширину (BFS)
  без рекурсии;
- учитывает максимальную глубину анализа;
- не учитывает пакеты, в имени которых есть заданная подстрока;
- правильно обрабатывает циклические зависимости;
- работает с тестовым репозиторием (файл с пакетами `A`, `B`, `C`...);
- показывает обратные зависимости (кто зависит от пакета) в тестовом режиме;
- печатает граф на языке диаграмм D2 и (по параметру) в виде ASCII-дерева.

## 2. Описание функций и настроек

Все настройки задаются параметрами командной строки.

| Параметр | Что означает |
|----------|--------------|
| `--package ИМЯ` | имя анализируемого пакета (обязательный) |
| `--repo ЗНАЧЕНИЕ` | URL репозитория; в тестовом режиме - путь к файлу. По умолчанию `https://pypi.org/pypi` |
| `--test` | тестовый режим: `--repo` это путь к файлу с описанием графа |
| `--ascii` | вывод в виде ASCII-дерева (работает с этапа 5) |
| `--depth N` | максимальная глубина анализа, от 1 до 50 (по умолчанию 3) |
| `--filter ТЕКСТ` | не учитывать пакеты, в имени которых есть эта подстрока |
| `--debug` | при запуске показать все параметры в виде `ключ = значение` |
| `--reverse` | показать обратные зависимости (только вместе с `--test`) |

Все ошибки (неверное имя, глубина, URL, нет файла и т.д.) печатаются
в виде `Ошибка: ...`, программа завершается с кодом 1.

Формат файла тестового репозитория: одна строка на пакет, имена - большие
латинские буквы, после двоеточия зависимости через пробел. Пустые строки
и строки с `#` пропускаются:

```
A: B C
B: D
C: D
D:
```

Вывод D2 можно вставить на сайт https://play.d2lang.com или
сохранить в файл `.d2` вне репозитория и открыть в программе D2.

## 3. Сборка и запуск тестов

Программа использует только стандартную библиотеку Python 3, собирать
ничего не нужно.

Тесты (Windows):

```
.\test.bat
```

или

```
set PYTHONPATH=src
python -m unittest discover -s tests -v
```

Демонстрационный сценарий этапа: `.\scripts\stage5.bat`.

## 4. Примеры использования

```
python src\depgraph.py --package A --repo tests\repos\big.txt --test --ascii --depth 3
python src\depgraph.py --package A --repo tests\repos\cycle.txt --test --ascii
python src\depgraph.py --package requests --ascii --depth 2
python src\depgraph.py --package D --repo tests\repos\simple.txt --test --reverse
```
