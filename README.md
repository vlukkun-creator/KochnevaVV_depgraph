# depgraph - граф зависимостей пакетов Python

## 1. Общее описание

Консольная программа на Python, которая строит граф зависимостей пакета
в формате pip (Python). Готовые менеджеры пакетов и сторонние библиотеки
для получения зависимостей не используются: данные берутся из JSON-описания
пакета на сайте репозитория (по умолчанию PyPI), а строки зависимостей
разбираются вручную.

Что умеет программа:

- получает прямые зависимости пакета по URL репозитория и печатает их;

## 2. Описание функций и настроек

Все настройки задаются параметрами командной строки.

| Параметр | Что означает |
|----------|--------------|
| `--package ИМЯ` | имя анализируемого пакета (обязательный) |
| `--repo ЗНАЧЕНИЕ` | URL репозитория; в тестовом режиме - путь к файлу. По умолчанию `https://pypi.org/pypi` |
| `--test` | тестовый режим: `--repo` это путь к файлу с описанием графа |
| `--ascii` | вывод в виде ASCII-дерева (работает с этапа 5) |
| `--depth N` | максимальная глубина анализа, от 1 до 50 (по умолчанию 3) |
| `--filter ТЕКСТ` | не учитывать пакеты, в имени которых есть эта подстрока |
| `--debug` | при запуске показать все параметры в виде `ключ = значение` |

Все ошибки (неверное имя, глубина, URL, нет файла и т.д.) печатаются
в виде `Ошибка: ...`, программа завершается с кодом 1.

## 3. Сборка и запуск тестов

Программа использует только стандартную библиотеку Python 3, собирать
ничего не нужно.

Тесты (Windows):

```
test.bat
```

или

```
set PYTHONPATH=src
python -m unittest discover -s tests -v
```

Демонстрационный сценарий этапа: `scripts\stage2.bat`.

## 4. Примеры использования

```
python src\depgraph.py --package requests
python src\depgraph.py --package flask --debug
```
